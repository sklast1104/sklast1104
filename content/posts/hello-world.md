## 블로그 시작

Hugo와 PaperMod 테마를 사용해 기술 블로그를 시작했습니다.

## 왜 Hugo인가?

- 빌드 속도가 빠름
- Markdown으로 글 작성
- GitHub Pages 무료 호스팅
- 다양한 테마

## 코드 예시

```csharp
public class HelloWorld : MonoBehaviour
{
    void Start()
    {
        Debug.Log("Hello, World!");
    }
}
```

## Mermaid 다이어그램

```mermaid
graph LR
    A[글 작성] --> B[Git Push]
    B --> C[GitHub Actions]
    C --> D[블로그 배포]
```

## 이미지 넣는 방법

```markdown
![이미지 설명](/images/posts/hello-world/example.png)
```

이미지는 `static/images/posts/포스트명/` 폴더에 저장하면 됩니다.
