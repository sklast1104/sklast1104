> 이 글은 GDC 2015의 *"Guilty Gear Xrd's Art Style: The X Factor Between 2D and 3D"* 발표와 개인적인 학습 내용을 정리한 포스트입니다.

## 1. 서론: 2D 같은 3D의 비밀

길티기어 Xrd(Guilty Gear Xrd)가 처음 공개되었을 때, 많은 게이머와 개발자들은 충격에 빠졌습니다. 완벽한 2D 셀 애니메이션처럼 보였지만, 실제로는 카메라가 360도로 회전하는 풀 3D 그래픽이었기 때문입니다.

특히 가장 놀라운 점은 **카메라가 아무리 확대되어도 절대 깨지지 않는 선명한 라인(Line)**이었습니다. 보통의 3D 게임 텍스처는 가까이 가면 픽셀이 튀거나 흐릿해지기 마련인데, 길티기어의 라인은 벡터 이미지처럼 언제나 날카로웠습니다.

이 글에서는 그 비밀인 **UV 트릭(UV Trick)**과 **안티에일리어싱(Anti-Aliasing)** 기법을 분석해 봅니다.

---

## 2. 기존 방식의 문제점: 계단 현상(Aliasing)

### 픽셀의 한계
디지털 화면은 정사각형 픽셀의 격자(Grid)로 이루어져 있습니다. 이 때문에 부드러운 곡선을 표현하려고 해도, 픽셀 격자와 완벽하게 정렬되지 않으면 필연적으로 **계단 현상(Aliasing)**이 발생합니다.

```
현실의 곡선:              디지털 화면:
                          ┌─┬─┬─┬─┬─┐
    ╭───╮                │ │ │█│ │ │
   ╱     ╲               ├─┼─┼─┼─┼─┤
  │       │      →       │ │█│ │█│ │  ← 계단 현상!
   ╲     ╱               ├─┼─┼─┼─┼─┤
    ╰───╯                │█│ │ │ │█│
                         └─┴─┴─┴─┴─┘
```

### 텍스처 방식의 한계
일반적인 게임 캐릭터는 텍스처(이미지)에 선을 그려서 모델에 입힙니다. 하지만 텍스처는 **해상도가 고정**되어 있습니다 (예: 1024x1024, 2048x2048).

*   카메라가 멀리 있을 때: 문제 없음.
*   **카메라가 클로즈업 할 때**: 텍스처의 픽셀 하나가 화면의 여러 픽셀 크기로 확대되면서 이미지가 깨지거나 흐릿해집니다.

길티기어 Xrd는 전투 중 강렬한 클로즈업 연출이 많기 때문에, 단순한 텍스처 매핑으로는 고품질의 라인을 유지할 수 없었습니다.

---

## 3. 해결책: 3D 메시에 최적화된 벡터 그래픽

이 문제를 해결하기 위해 개발팀은 **벡터 그래픽(Vector Graphics)**의 원리를 차용했습니다.

*   **래스터(텍스처)**: "이 픽셀은 검은색, 저 픽셀은 흰색"으로 저장. 확대하면 깨짐.
*   **벡터**: "여기서 여기까지 반지름 3인 원을 그려라"라는 **수학적 공식**으로 저장. 확대해도 매번 새로 계산하므로 선명함.

하지만 렌더링 파이프라인에서 순수 벡터 방식을 그대로 쓰기에는 무거울 수 있습니다. 그래서 고안된 것이 바로 **UV 트릭**입니다.

---

## 4. 핵심 기법: UV 트릭 (Inner Line)

UV 트릭의 핵심은 **"선을 그리는 것이 아니라, 계산하는 것"**입니다. 텍스처에 선을 그려넣는 대신, 셰이더가 실시간으로 UV 좌표를 계산해 선을 만들어냅니다.

### 작동 원리

1.  **셰이더 규칙**: "UV 좌표가 0.5 근처이면 검은색 선을 칠한다."
2.  **모델링(메시)**: 선을 넣고 싶은 부위의 버텍스(Vertex) UV 좌표를 조작합니다.
    *   선의 한쪽 끝 버텍스 UV: `0.0`
    *   선의 반대쪽 끝 버텍스 UV: `1.0`
3.  **GPU 보간(Interpolation)**: GPU는 버텍스 사이의 픽셀들을 칠할 때, UV 값을 자동으로 부드럽게 보간합니다.
    *   `0.0`에서 `1.0`으로 가는 중간 어딘가에 반드시 `0.5`인 지점이 생깁니다.
    *   셰이더는 바로 그 지점에 선을 그립니다.

### 곡선 표현의 마법
이 방식이 강력한 이유는 **메시의 형태를 따라 선이 휘어지기 때문**입니다.

```
상단 버텍스들 ●───●───●───●───● (UV = 1.0)
             \   \   \   \
              \   \   \   \  <- 이 사이 어딘가 UV=0.5 지점에 선이 생김
               \   \   \   \
하단 버텍스들 ●───●───●───●───● (UV = 0.0)
```

버텍스를 곡선으로 배치하면, 그 사이의 `UV=0.5` 지점도 수학적으로 완벽한 곡선을 이루게 됩니다. 이를 화면 해상도에 맞춰 실시간으로 렌더링하기 때문에, **아무리 확대해도 절대 깨지지 않는 무한 해상도의 선**을 얻을 수 있습니다.

### 셰이더 코드 예시 (HLSL)

학습한 내용을 바탕으로 재구성한 간단한 셰이더 로직입니다.

```hlsl
half4 frag(Varyings IN) : SV_Target
{
    // GPU가 보간해준 UV2 값 (보통 라인용으로 별도 UV 채널 사용)
    float uvY = IN.uv2.y;

    // 라인 두께 설정
    half halfThickness = _LineThickness * 0.5;

    // UV가 0.5 범위 내에 있는지 확인 (Step 함수 사용으로 안티에일리어싱 처리 가능)
    // 0.5 - 두께 < UV < 0.5 + 두께
    half lineMask = step(0.5 - halfThickness, uvY) * step(uvY, 0.5 + halfThickness);

    // 최종 색상 혼합
    return lerp(_BaseColor, _LineColor, lineMask);
}
```

## 5. 실제 적용 및 한계

### 적용 방식
길티기어의 캐릭터 모델은 여러 UV 채널을 사용합니다.
*   **UV1**: 일반적인 피부색, 옷 색상 등의 텍스처 매핑.
*   **UV2**: 얼굴 주름, 근육 묘사 등 **내부 라인(Inner Line)** 표현용.
*   **Vertex Color**: 그림자 제어 (S.S.S.O 등).

### 한계점
*   **모델링 난이도**: 아티스트가 라인을 넣고 싶은 곳마다 메시의 흐름(Topology)을 설계하고 UV를 정교하게 펴야 합니다.
*   **평행선 문제**: 두 개의 선이 매우 가깝게 붙어있으면 UV 보간이 꼬일 수 있어 메시를 나눠야 할 수도 있습니다.

---

## 6. 결론

길티기어 Xrd의 렌더링은 "2D처럼 보이게 하기 위해 3D의 기술적 한계를 수학적으로 극복한 사례"입니다. 단순히 텍스처 해상도를 높이는 무식한 방법 대신, **GPU의 보간 특성(Interpolation)**을 역이용하여 벡터 그래픽의 장점을 3D로 가져온 천재적인 발상이라고 생각합니다.

이 기법은 현재의 *드래곤볼 파이터즈*, *길티기어 STRIVE* 등으로 이어지며 카툰 렌더링의 표준 중 하나로 자리 잡았습니다.
